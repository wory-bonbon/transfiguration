## 0. 要約

RAW 版は幾何の長さを**基音の周波数**へ写像した。本拡張は同じ原理を**音色（倍音構成）**へ延長する。

> 各 voice の部分音の周波数比率を、その瞬間の多面体自身の長さの比から導出する。
> 基音だけでなくスペクトル全体が幾何の写像になる。

ガラス・ベル系の音の正体は「非整数比で並ぶ部分音の集合」である。多面体のクラス長比は元来非整数比なので、幾何比率をそのまま部分音比率に使うことで、外部音源もプリセットも使わずにガラス的な質感（v1.1 §9.1 の glass / crystal resonance 方向）へ近づく。

これは音を「足す」のではなく、既存の写像を音色次元へ拡張するものであり、**RAW の哲学（v1.1 §3.1、CLAUDE.md の RAW 定義）に完全準拠する**。スケール量子化・録音素材・サンプルは引き続き使用しない。

### v0.1 からの設計上の転換（重要）

v0.1 の導出規則には、次の恒等式による構造的な問題があった。

```text
f_i = f0 · L_ref / L_i        ← v1.1 §4.2 の周波数式
r   = L_i / L_k

f_i · r = f0 · L_ref / L_i · L_i / L_k = f0 · L_ref / L_k = f_k
```

**すなわち「クラス長比を部分音比率にする」と、部分音は必ず別クラスの基音に一致する。** v0.1 §3.2 の数値例（Ico voice A: 110 Hz → 部分音 190.5 Hz）自体がそれを示していた。190.5 Hz は v1.1 §23.6 のクラスC の基音そのものである。

したがって v0.1 の設計では、聴感上の効果は「新しいスペクトルの追加」ではなく「既に鳴っている周波数の重み付け変更」にとどまる。

v0.2 は自己相似方式 `{r, r²}` を採る。

```text
f_i · r   = f_k              既存の基音に重なる（強調として機能）
f_i · r²  = f0 · L_ref · L_i / L_k²    ← 既存集合に存在しない新しい周波数
```

第1部分音が既存周波数を強調し、第2部分音が幾何由来の新しい成分を作る。比率は依然として多面体自身の長さのみから導かれるため、RAW 原則は維持される。

## 3. 部分音の導出規則（v0.2 全面改訂）

### 3.1 自己相似方式

各 voice は（クラス c、モード m ∈ {1, 2}、自長 L）の3つ組を持つ。F2 のとおり、この対応はモードごとに独立である。

```text
voices[2k]    :  c = SND_CLS[sndOrd[k]] ,  m = 1 ,  L = c.len
voices[2k+1]  :  c = SND_CLS[sndOrd2[k]],  m = 2 ,  L = c.len2
```

候補プールは**モードごとに分離する**。第1モード voice が第2モード長を参照すると、順序が独立に動く2系統（F2）が結合し、フリッカーの原因になる。

```text
P₁ = { SND_CLS[j].len  | j = 0..3 }
P₂ = { SND_CLS[j].len2 | j = 0..3 }
```

voice i（自長 L_i、モード m_i）に対して：

```text
r_i = min { L_i / L | L ∈ P_{m_i} ,  ε·L_i ≤ L < L_i }        ε = 0.05

部分音周波数 :  f_i · r_i  ,  f_i · r_i²
```

1. `r_i` は 1 より大きい比率のうち**最小のもの**。すなわち自分より1段だけ短い代表長との比
2. 候補が存在しない場合、その voice は**部分音を持たない**（部分音ゲインを 0 へフェード）。最短の代表長を担当する voice は常にこれに該当する
3. `ε = 0.05` により `r ≤ 20`、`r² ≤ 400` に自動的に収まる。それでも上限側は §3.3 のゲートが処理する
4. 比率は毎更新で長さから導出されるため、形態変化に伴い部分音も連続的に動く（追加の補間処理は不要。25Hz パス＋Web Audio automation で v1.1 §12 のまま）

#### ε 条件が「ゲイン > 0」より適切な理由

退化クラスは `weight → 0` へ**なめらかに**落ちるため（F3 / `SND_WBAND`）、「ゲイン > 0」では「実質無音だが weight は微小に正、長さはほぼ 0」という区間を必ず通過する。このとき `L_i / L_k` が発散する。

さらに F3 のとおり `len` は退化後も前回値を保持するので、長さが極小のまま凍結しうる。相対しきい値 `L_k ≥ ε·L_i` はこの両方を同時に排除する。ゲイン条件は不要となる（退化クラスの `len` は 0 付近まで追随してから凍結するため、ε 条件が包含する）。

#### この表から読み取れること

- **全状態を通じて r は 4 値しか現れない。** `2sin36° = 1.175571`、`√3/(2sin36°) = 1.473364`、`φ = 1.618034`、`√3 = 1.732051`。いずれも多面体の基本比であり、幾何との対応を説明できる（v1.1 §31-4）

- **`r²` が整数になる状態がある。** Ico voice A と TD voice A/B は `r² = 3` ちょうど。これは √3 の二乗という幾何の帰結であり、欠陥ではない。ただし v0.1 §3.2 の「整数比にならないこと」という主張は誤りなので撤回する。部分音の集合 `{1, √3, 3}` は全体としては非調和である

- **最短クラスの voice は常に部分音を持たない。** 4クラスすべてが鳴る状態（ti / td / id）では 8 voice 中 2 voice（第1・第2モードそれぞれの最短）が該当する

#### 第2モードの基準値について

第2モード長 `len2` は面の apothem / apex→辺中点距離の重み付き幾何平均であり（F1）、σ にも依存するため、解析的に事前算出しない。**Phase M1 で実測して本節に追記する**（§11）。AC-M2 は第1モードのみを対象とする。

### 3.3 範囲外の扱い

部分音周波数にも、基音とまったく同じ **`sndGate(f)`** を適用する（F4）。

```text
f ≤ 26 Hz          → gain 0
26 – 45 Hz         → smoothstep でフェードイン
45 – 3000 Hz       → gain 1
3000 – 6000 Hz     → smoothstep でフェードアウト
f ≥ 6000 Hz        → gain 0
```

clamp は行わない（v1.1 §4.2）。`r² ≤ 400` により最悪ケースでも `f · r²` は有限だが、多くの状態で 6 kHz を超えて自動的に無音になる。これは意図した挙動である。

非有限値は v1.1 §18.1 の防御をそのまま適用し、`Number.isFinite()` 検査を通さない値を AudioParam へ渡さない。周波数が無効な場合は直前の有効値を保持し、ゲインのみ 0 へフェードする（`sndApply()` と同じ規約）。

## 4. 部分音のゲイン設計

```text
g_k = g_0 · ρ^k · w_r · sndGate(f_i · r^k) · norm        （k = 1, 2）

ρ    = ρ_base + ρ_sig · σ_normalized
       デフォルト: ρ_base = 0.35 , ρ_sig = 0.25（ρ 上限 0.6）

w_r  = §6 の r→1 フェード係数

norm = 1 / √(1 + ρ² + ρ⁴)      パワー和正規化
```

`g_0` は既存実装の voice ゲイン（`SND_GBASE · weight · SND_M2^(mode-1) · sndGate(f_i)`）をそのまま使う。

1. σ = 0（非星形）では ρ = 0.35。部分音は基音の −9 dB に収まり、RAW v1 の印象を大きく変えない
2. σ 増加で部分音が立ち上がる。v1.1 §6.2「星形化で高域・倍音が増える」を、フィルタではなく実部分音で実現する。**既存の固定フィルタ（lowpass 5000 Hz / Q 0.7）は変更しない**。modal モードにおける高域の増減は ρ_sig のみで制御する（§10-4 確定）
3. **正規化はパワー和で行う。** 異周波数の正弦波は非コヒーレントに加算されるため、振幅和 `1/(1+ρ+ρ²)` で割ると σ = 0 で約 −3.4 dB 下がり、AC-M1 と衝突する。パワー和なら σ = 0 で −0.55 dB、ρ 上限 0.6 でも −1.7 dB に収まる
4. 最終的なクリップ防止は既存の Compressor（threshold −12 dB / ratio 12）が担う。v1.1 §11 のグラフは変更しない

## 5. Audio Graph の変更（Voice 内部のみ）

```text
[v1 RAW]   Osc → Gain → Filter ─┐
                                 ├→ Voice Mix → Compressor → Master Gain → Destination
[v0.2]     Osc(基音)   → g_0 ┐   │
           Osc(部分音1) → g_1 ├→ Filter ┤（voice 内で合流）
           Osc(部分音2) → g_2 ┘   │
```

- 部分音 Oscillator は既存の voice Filter の**前段**で合流させる。安全ロールオフ（lowpass 5000 Hz）を部分音にも効かせるため
- 外側のグラフ（Mix 以降）は v1.1 §11 から**一切変更しない**。StereoPanner（P2）の挿入位置も v1.1 のまま
- 部分音ノードは `?timbre=modal` のときだけ生成する（AC-M1）
- v1.1 §4.1 のとおり、AudioNode をフレームごとに生成・破棄しない。初期化時に確保し、以後はパラメータのみ更新する

## 6. Voice tracking の拡張

v1.1 §24 の原則を部分音へも適用する。自己相似方式では voice ごとの独立変数が `r` ひとつになるため、v0.1 §6-1 が要求した「部分音 index の入替禁止」は自動的に満たされる。

### 6.1 順序交差点の連続性

`r` が不連続になりうるのは、**自分より短かったクラスが自分を追い越す瞬間**のみである。この瞬間は定義上 `L_k = L_i`、すなわち `r = 1` であり、部分音は基音に一致している。したがって周波数は連続である。

Dod → SSD 遷移（AC-M4）の実際：

```text
Dodecahedron   L_A = 0.7639 > L_C = 0.6498
               voice A : r = 1.1756          voice C : 候補なし

  ── 遷移中、σ の増加で L_C が伸び、L_A を追い越す ──

交差点          L_A = L_C
               voice A : r → 1.0（部分音が基音へ収束）
               voice C : r → 1.0（部分音が基音から分離開始）

SSD            L_C = 1.2361 > L_A = 0.7639
               voice C : r = φ               voice A : 候補なし
```

部分音は voice A から voice C へ「乗り移る」が、その受け渡しは常に `r = 1`（＝基音そのもの）の位置で起こる。周波数ジャンプは発生しない。

### 6.2 `r → 1` フェード（必須）

ただし `r ≈ 1` では基音・第1部分音・第2部分音が同一周波数へ重なり、**コヒーレント加算**になる。振幅が `1 + ρ + ρ²` 倍（ρ = 0.35 で約 +2.8 dB）に膨らみ、v1.1 §17 の「sudden gain jump 防止」と衝突する。

したがって次のフェード係数を必須とする。

```text
w_r = smoothstep( (r − 1) / δ )        δ = 0.05（§10-6 確定。Phase M3 で調整可）

r ≤ 1.00  → w_r = 0
r ≥ 1.05  → w_r = 1
```

これにより、候補集合への出入り（部分音の出現・消滅）も自動的にゲインフェードになり、v0.1 §6-2 の要求を兼ねる。

### 6.3 その他

1. 基音の voice tracking 挙動は変更しない
2. `r` の平滑化は不要。25Hz パスで再計算された `r` から算出した部分音周波数を、基音と同じ `setTargetAtTime(·, t, SND_TC_F)` へ渡す
3. 部分音ゲインも基音と同じ `SND_TC_G` を使う

## 9. 受け入れ基準（AC-M）

| # | 基準 |
|---|---|
| AC-M1 | パラメータなしで RAW v1 と聴感・実装経路が同一（部分音ノードを生成しない） |
| AC-M2 | 第1モードの部分音比率が §3.2 の表と一致する（±0.001）。最重点は **Icosahedron voice A = (√3, 3)** と **Small Stellated Dodecahedron voice C = (φ, φ² = φ+1)** |
| AC-M3 | ti / td（A = B = C が同一長になる状態）で例外・無音化・NaN が発生せず、最短クラス voice が部分音なしで正常動作する |
| AC-M4 | Dod → SSD 遷移中、部分音が voice A から voice C へ `r = 1` を経由して受け渡され、周波数ジャンプが発生しない（§6.1） |
| AC-M5 | σ = 0 → max の掃引で部分音ゲインが単調に増加する |
| AC-M6 | L→0 系の全遷移（v1.1 AC-15 の対象）で非有限値が AudioParam に渡らない。ε 条件により `r` が 20 を超えない |
| AC-M7 | Sound OFF 時に部分音関連の計算・ノードが動作しない |
| AC-M8 | `Math.random()` 不使用・同一状態で常に同一スペクトル |
| AC-M9 | 順序交差点（`r → 1`）で基音のゲインが +1 dB を超えて膨らまない（§6.2） |
| AC-M10 | v1.1 の全 AC（特に AC-05 / AC-10 / AC-15）が `?timbre=modal` 状態でも維持される |
